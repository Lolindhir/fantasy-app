# Player Knowledge

Derived league-relevant Knowledge about individual players.

Use this only after source takes have been checked against our league format and current context.

A player Knowledge entry should answer:

- What source-backed statements matter for this player?
- Which team and position context affects the player?
- Which statements are Dynasty-relevant for our format?
- Which statements are only redraft, market or historical context?
- Which source package and take IDs support the current view?
