# Fantasy Management Knowledge

Purpose: derived, league-relevant working knowledge.

Knowledge is not raw podcast extraction.

Podcast source packages answer:

> What did the source say?

Knowledge answers:

> What of that matters for our league, format, roster context and current decisions?

Analyses answer:

> What should Mighty Giants do?

## Structure

```text
knowledge/
  players/
  teams/
  positions/
  nfl/
  fantasy/
```

## Derivation rules

- Derive Knowledge only after source takes have been reviewed against league context.
- Do not copy every podcast take into Knowledge.
- Redraft-only source takes may remain only in the source package if they do not matter for Dynasty.
- Redraft takes that affect market value may become fantasy-market Knowledge instead of player-quality Knowledge.
- Link Knowledge entries back to source package paths and take IDs for evidence.
- Re-check current app data and external news before using Knowledge for final recommendations.
