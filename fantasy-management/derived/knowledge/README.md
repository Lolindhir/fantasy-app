# Fantasy Knowledge Layer

This folder stores cross-source, derived fantasy-football knowledge.

It separates source evidence from the current working view:

- `takes/` keeps historical source takes.
- `current/` keeps the latest source-derived view.
- `entities/` keeps aliases and source registries.
- `rollups/` keeps dated cross-source summaries.

Raw transcripts stay under `fantasy-management/sources/`. Concrete recommendations stay under `fantasy-management/analyses/`.
