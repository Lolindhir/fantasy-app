# KeepTradeCut

KeepTradeCut gehört fachlich zur Ranking-Art `market-value`, weil die Quelle Crowd- und Marktstimmung für Dynasty-Spieler und Draftpicks abbildet.

## Nutzungsstatus

```text
manual_reference_only
```

KeepTradeCut veröffentlicht nach aktuellem Stand keine freigegebene API oder CSV und untersagt automatisiertes Scraping beziehungsweise systematische Datenerfassung. Deshalb gibt es hier keinen Fetcher, keinen Workflow und keine gespeicherten vollständigen Rankings.

Einzelne Werte oder Tendenzen dürfen bei einer konkreten Analyse manuell geprüft, datiert und sichtbar als KeepTradeCut-Quelle gekennzeichnet werden. Eine automatisierte Integration setzt eine geänderte veröffentlichte Richtlinie oder ausdrückliche Genehmigung voraus.
