# StonedLack 569 Episode Package

This folder is the simplified source package for StonedLack episode 569.

## Files

- `episode.md` — clean German podcast summary without internal extraction metadata.
- `takes.json` — categorized podcast source takes.
- `index.json` — local package metadata and take counts.
- `raw/manifest.md` — raw transcript manifest pointing to the existing legacy split raw transcript.

## Layer separation

This folder contains source material only.

It does not contain derived Knowledge and does not contain Mighty Giants recommendations.

Derived Knowledge should be created separately under `fantasy-management/knowledge/` when the source takes are interpreted against league format, roster context and current data.
