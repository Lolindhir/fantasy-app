# StonedLack Source Notes

Dieses Repo enthält strukturierte Extraktionen aus StonedLack-Podcastfolgen.

## Workflow

Pro Folge werden drei Artefakte gespeichert:

1. Raw-Transkript unter `raw_transcripts/YYYY/`
2. Markdown-Quellennotiz unter `episodes/YYYY/`
3. JSON-Datenfile unter `episodes/YYYY/`

Die Regeln stehen in `STONEDLACK_EXTRACTION_GUIDE.md`.  
Das maschinenlesbare Schema steht in `schemas/stonedlack_take_schema.json`.
