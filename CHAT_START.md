# Chat Start Rules

Repository: `Lolindhir/fantasy-app`

Before suggesting or making repository changes:

1. Read `AGENTS.md` in the repository root.
2. Follow the required `.ai-context` reading order defined there.
3. Read `TODO.md` in the repository root to understand open implementation, cleanup and documentation tasks.
4. Treat `.ai-context` as the canonical AI context documentation.
5. Treat `TODO.md` as the canonical open todo list for actionable project work.
6. Do not create parallel AI context documentation outside `.ai-context` unless explicitly requested.
7. Do not create additional todo lists outside `TODO.md` unless explicitly requested.
8. When the user asks to remember or track a project todo, add it to `TODO.md` in German.

Short prompt for new chats:

```text
Repo: Lolindhir/fantasy-app. Please read AGENTS.md first, then follow the required .ai-context reading order, and read TODO.md before suggesting or making repository changes. Treat TODO.md as the canonical open todo list and record new project todos there in German.
```
